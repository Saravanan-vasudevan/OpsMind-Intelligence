# OpsMind

Manufacturing operations analytics: plants, lines, shifts, equipment, production and downtime records, KPI dashboards and CSV export, with multi-tenant isolation and role-based access.

This is a portfolio project. All demo data is **synthetic** and generated by a seeded script; no real company data is used.

**Current version: V1 (full-stack core).** Later versions (data intelligence, AI assistant) are planned in `docs/BLUEPRINT.md` and are **not** implemented yet.

## What V1 implements

| Area | Implemented |
|---|---|
| Auth | Register an organisation, login/logout, JWT in an HttpOnly cookie, CSRF header check, password change, roles Admin/User, user management (admin), inactive users rejected |
| Structure | Plants, production lines, shifts (overnight supported), equipment categories, equipment |
| Data entry | Production records (with optional quality figures) and downtime events, validated server-side |
| Analytics | Summary KPIs, trend (day/week/month), plant comparison, downtime by reason — all computed by the API from stored records |
| Export | CSV of production records with formula-injection protection |
| Admin | Audit log, user management |
| Platform | SQL-first migrations, tenant isolation via EF global query filters, ProblemDetails errors, health endpoints, Swagger, rate limit on auth |
| Frontend | Login/register, overview dashboard (filters, KPI cards, charts with table view), plants/lines/shifts, equipment, data entry, users, audit log, account |

KPI formulas are in `docs/KPI_DEFINITIONS.md`. Known limitations are in `docs/KNOWN_LIMITATIONS.md`.

## Run it

Requirements: Docker Desktop, or .NET 10 SDK + Node 22 + PostgreSQL 16.

```bash
cp .env.example .env        # edit POSTGRES_PASSWORD and JWT_SECRET
docker compose up --build
```

- App: http://localhost:3000
- API Swagger: http://localhost:8080/swagger
- With `SEED_DEMO_DATA=true`, an empty database is filled with synthetic data. Demo login: `demo.admin@opsmind.example` (admin) or `demo.user@opsmind.example`, both with the demo-only password `Demo-Passw0rd!`.

Without Docker:

```bash
# backend (needs Postgres and env vars from .env.example)
cd backend && dotnet build OpsMind.slnx && dotnet test OpsMind.slnx
cd src/OpsMind.Api && dotnet run          # listens per launch settings / ASPNETCORE_URLS

# frontend (dev proxy sends /api to http://localhost:8080)
cd frontend && npm ci && npm run dev
```

## Tests

```bash
cd database/tests && npm ci && npm test     # schema + model consistency
cd frontend && npm test && npm run typecheck && npm run build
```
